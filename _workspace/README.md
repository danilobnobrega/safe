# _workspace — what lived only on Danilo's machine

Snapshot (2026-10-09) of the working folders behind GENERIC that were never in the repo:

- `garage-blender/` — the garage scene build (Blender 4.5 scripts: studio.py, poses.py, custom_props.py…), Poly Haven sources (`ph/`), the HDRI, exports (`out/`) and preview renders (`prev/`). Left out: the MakeHuman/MPFB installers (`mh_assets.zip`, `mpfb.zip`, `hbm.zip` — re-downloadable; one is over GitHub's 100 MB limit).
- `tunnel-models/` — the tunnel objects: each source model as downloaded (`<name>/model.glb`), the Blender prep scripts (`prep.py`, `levels.sh`, `fuzz.py`, `bend.py`…) and check renders. Sketchfab models are CC-BY: authors in `CREDITS.txt`.
- `backups/` — the site before the page cleanup, the garage variants, the old and new letter photo sets, the garage scene before the hands fix, and the first proposals.

Not included (public repo): third-party site code studied for reference (steven.com, damngoodbrands), and the discarded portrait photo.
