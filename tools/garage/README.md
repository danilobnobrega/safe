# garage scene — build pipeline

Everything in `public/garage/` is generated by these scripts (headless Blender 4.5 + Python).

Sources (all CC0): Poly Haven models + the `garage` HDRI, MakeHuman people via the MPFB
extension (`makehuman_system_assets_cc0` pack). Textures in `gen_textures.py` are drawn from scratch.

1. Put Poly Haven glTFs (1k, with textures) in `ph/<asset>/`, `garage_2k.hdr` next to the scripts,
   install MPFB (`blender --command extension install-file -r user_default -e mpfb.zip`) and unzip
   the MakeHuman CC0 pack into MPFB's user data dir.
2. `blender -b --python scene.py -- preview`  -> `prev/scene.png` (web camera) + `prev/scene_top.png`
3. `blender -b --python scene.py -- export`   -> `out/garage.glb` (+ baked floor AO, Draco)
4. `blender -b --python scene.py -- photos`   -> `prev/photos/00..23.png` (the photo ring; packed into
   `photos.jpg` 4x6 atlas + `background-0/1.png` bands)
5. `python gen_textures.py` -> drawing / drawing-cursor / noise / concrete
